# Design review

Compare the design to the same outline the architect used.

- A required section with no text and no explicit "none" is a blocker.
- Call out missing failure behavior, rollout, and verification.
- Do not require a company-specific template. The active markdown file is the contract.
- Return a short list of blockers and non-blockers. Do not rewrite the design in place.
